# RTSP再接続

再接続遅延は1、2、4、8、15、30秒の指数バックオフを基本とし、最大30秒へ制限します。ジッターは±20%の範囲で加え、30秒以上安定再生できた場合は試行回数をリセットします。

RendererがLibVLCのエラーを受けた場合、GUIをクラッシュさせずに失敗状態として表示します。再接続ボタンは最後のRendererStartOptionsを使ってMediaPlayerを破棄・再生成します。

壁紙表示後はRendererが2秒ごとに、親ウィンドウ配置とLibVLCの再生ヘルスを確認します。`Playing`、`VoutCount > 0`でも映像時間の進行が8秒以上停止した場合は、`RTSP_PLAYBACK_STALLED`として記録し、壁紙をいったん非表示にしてMediaPlayerを再生成します。再接続中の重複操作はRenderer内の排他ロックで直列化します。配信元が復帰すれば同じ壁紙配置トランザクションを通過して再表示し、復帰しない場合は黒画面を成功扱いにせず、GUIへエラーを表示します。

本公開版で長時間再生を行う場合は、メモリ、ハンドル、スレッド、MediaPlayerの破棄を確認してください。
