# RTSP再接続

再接続遅延は1、2、4、8、15、30秒の指数バックオフを基本とし、最大30秒へ制限します。ジッターは±20%の範囲で加え、30秒以上安定再生できた場合は試行回数をリセットします。

初回接続は、LibVLCの `Playing` と `VoutCount > 0` だけでは成功扱いにしません。メディア時刻の進行を複数回確認し、バッファリング中の停止や初期の早送りを壁紙表示前に排除します。配信元が起動直後にまだ準備できていない場合は、最大5回のバックオフ再試行を行い、最後にだけFatalErrorを通知します。

壁紙表示後はRendererが2秒ごとに、親ウィンドウ配置とLibVLCの再生ヘルスを確認します。`Playing`、`VoutCount > 0`でも映像時間の進行が8秒以上停止した場合は、`RTSP_PLAYBACK_STALLED`として記録し、壁紙をいったん非表示にしてMediaPlayerを再生成します。再接続は最大6回まで1、2、4、8、15秒のバックオフで継続し、配信元が復帰すれば同じ壁紙配置トランザクションを通過して再表示します。再接続中の重複操作はRenderer内の排他ロックで直列化します。復帰しない場合は黒画面を成功扱いにせず、GUIへエラーを表示します。

本公開版で長時間再生を行う場合は、メモリ、ハンドル、スレッド、MediaPlayerの破棄を確認してください。
