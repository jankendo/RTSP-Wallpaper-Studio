# セキュリティ

- URLは`rtsp` / `rtsps`だけ受け付けます。
- URL内資格情報は保存URLから分離します。
- パスワードはWindows DPAPI `CurrentUser`スコープで保護します。固定暗号鍵はソースへ埋め込みません。
- IPCパイプ名にプロセスIDとランダムセッションIDを含め、サーバー側は`PipeOptions.CurrentUserOnly`を利用します。
- IPCメッセージは64 KiB上限とJSON検証を行います。
- URLクエリはログ用に伏せ、完全な認証付きURLやパスワードをログへ出しません。
- URLをシェルコマンド文字列へ連結しません。LibVLCオプションはアプリ側で固定した値だけを使用します。

実際の配布では、診断ZIP、クラッシュレポート、スクリーンショットへ資格情報が混入しないことを追加監査してください。
